# ADR 0003: OpenAI כותב, Claude מנתח

תאריך: 16 בספטמבר 2026
סטטוס: התקבל. המימוש בשלב 2 ובשלב 5.

## החלטה

- **כתיבה**: כל טקסט שגולש רואה, וגם הצ׳אט, נכתב על ידי המודל המתקדם ביותר של OpenAI. שם המודל הוא ערך הגדרה שנקבע מול רשימת המודלים החיה, לא קבוע בקוד.
- **ניתוח**: חילוץ מאפיינים, סיווג, ביקורת, תכנון והכרעה נעשים ב־Claude.
  - Claude Haiku 4.5 לעבודה ההמונית, ב־Message Batches בחצי מחיר.
  - Claude Sonnet 5 להסלמה בלבד: טענות שהמעבר הראשון לא בטוח בהן, וטענות תאימות.
  - Claude Opus 5 למקרים נדירים: תכנון קטגוריה, הכרעה במחלוקת, דגימה אדומה.
- **חיבור**: SDK רשמי לכל ספק, מאחורי ממשק פנימי אחד שמקבל תפקיד ומחזיר תוצאה. הכריכה תפקיד → ספק → מודל נערכת מפאנל המפעיל.
- **בלי OpenRouter**: הוא לא חושף את Batch API של Anthropic, שהוא מנוף העלות השני בגודלו.

## למה

- כותב ומבקר ממשפחות שונות מקטינים שגיאות מתואמות.
- רוב הנפח הוא ניתוח. מודל קטן ב־Batch עם prompt caching על קידומת קבועה מוריד את העלות בסדר גודל.
- החלפת מודל או ספק צריכה להיות הגדרה, כי מחירים ומודלים משתנים כל כמה חודשים.

## השלכות

- כל קריאה נרשמת ב־ledger עם טוקני קלט, פלט, cache ו־batch, ומוצגת בפאנל המפעיל מהקריאה הראשונה.
- יש לאמת מחירים מול המחירון החי לפני קביעת תקציב.
